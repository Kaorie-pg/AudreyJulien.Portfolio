# Notes sur le portfolio

## Points importants

Attention aux consigne pas comprises

- Pourquoi il est pertinent pour le domaine qu'on vise (référencer la veille, la réflexion sur les couleurs, ...) EN JUSTIFIANT

- Démarche reflexive

Présentation d'un projet (4 min) :

Présenter un projet en s'appuyant sur le portfolio (beaucoup d'images, éléments pertinent, schéma).

Le projet doit être en lien avec le PPP.

**/!\ il faut faire le lien avec le stage/alternance**

Le portfolio doit être à jour avec les dernières expérience de stage.

Si le stage/alterance est confidentiels : il faut voir avec la structure ce qu'on peut dire du projet, utiliser beaucoup de figure et parler largement
